## 仓库切换状态流
- 仓库切换时 Provider 在选择事件边界立即清空旧 Changed Files/Diff 身份、取消旧请求，并将 filesLoading/diffLoading 置为 true。
- GitCommitController 在仓库事件入口清空旧 commit 数据、发布 commit loading，并主动消费 GitBranchesController 的当前选择快照，消除事件订阅顺序导致的新分支事件早到竞态。
- SelectedRepoTotalBranchWatcher 改为 HEAD -> 完整 refs 两阶段读取：先发布 HEAD 最小快照，再异步补齐完整分支。
- 坑: HEAD 最小快照会写入 totalBranches, 使 enqueueRefresh(force=false) 把它当成"完整分支已加载"而跳过完整刷新, 导致分支列表一直 loading (loadingEmitter 永不 fire(false))。修复: syncRepositories 进入前用 needsFullRefresh=!cachedBranches 记录是否已有完整快照, HEAD 最小快照不影响该判定, enqueueRefresh 传 needsFullRefresh 强制完整读取。
- 验证: npm run compile 成功，改动文件无 lint 诊断，git diff --check 通过。
