- **消除首屏「正在加载提交面板…」（已实施）**
  - 现象来源：`#loading` 从 HTML 解析起就可见，直到第一条 `snapshot` 消息走完 `render()` 才被置 `hidden`（`render()` 内 `app.hidden=false;loading.hidden=true`）。首次打开要付一遍 webview 冷启动 + **ready→postMessage→render 往返**，所以只有首开会看到。

  - 做法：把快照内联进 HTML，`getHtml(codiconsRoot, initialSnapshot)` 生成 `<script nonce id="gitk-initial-snapshot" type="application/json">`，webview 在 `postMessage({type:'ready'})` **之前**直接 `render(initial.cards)`，首次渲染与首次绘制同步完成。
  - 安全：`JSON.stringify(...).replace(/</g,'\\u003c')`，阻断内容里的 `</script>` 提前闭合标签（仓库路径/文件名可能含任意字符）；数据块也带 nonce。
