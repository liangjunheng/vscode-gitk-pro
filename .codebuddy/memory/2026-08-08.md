# 2026-08-08

- 修复分页加载提交时的分支图断连：`buildGraph` 的可见哈希集合现包含已加载提交的父提交哈希，首批构图会预留后续页父提交车道；`loadMoreCommits` 增量追加时可复用该车道，避免父提交重新开线。已通过 `tsc --noEmit` 与 `gitLogProvider.ts` linter 验证。
- 优化连续滚动分页性能与资源生命周期：`GraphState` 缓存 `visibleHashes`，追加页仅处理新增提交；预取 `git log --no-walk` 支持 `AbortSignal`，仓库/分支刷新、视图隐藏或销毁时取消；重试定时器被统一清理。Diff 面板隐藏/销毁时终止 `git cat-file` 子进程，且旧进程退出不会覆盖新进程引用。已通过全量 `tsc --noEmit`、相关 linter 和 `git diff --check`。
- 修复切换仓库时加载异常：`selectRepositories` 现在先清空 `refreshInFlight` 再启动新刷新，避免旧刷新 Promise 阻塞新仓库加载；`refreshInternal` 入口捕获 `refreshGen`，在并行块和顺序路径的关键 await 后均检查 `refreshGen !== this.refreshGeneration`，旧刷新发现世代变化即提前返回，不再向 webview 投递过期数据。
- 修复加载进度文案与实际操作不匹配：首次并行加载的初始文案从 "加载提交..." 改为 "正在加载仓库、分支和提交..."；切换仓库时 `beginCommitReload` 文案改为 "正在切换仓库..."；切换分支时改为 "正在切换分支..."。
- 修复内存泄漏：(1) `resolveWebviewView` 的视图级订阅 (onDidReceiveMessage/onDidChangeVisibility/onDidDispose) 从 `context.subscriptions` 移至独立 `viewDisposables` 数组，`onDidDispose` 和扩展停用时统一释放，避免视图反复创建时订阅累积。(2) `customDiffPanel.ts` 的 `onDidDispose` 回调新增 `stopChildProcess()` 调用，确保用户直接关闭 Diff 面板时 `git cat-file` 子进程也被终止。
- 修复初始化时多次加载仓库：`refreshWithRetry` 的 `skipSelectors` 逻辑从 `!isFirstAttempt` 改为 `!isFirstAttempt && this.hasBranchSelection`，首轮失败（选择器未加载成功）时重试不跳过选择器；并行块内 `refreshSelectors` 失败时直接抛出触发重试，不再落入顺序路径重复调用 `refreshSelectors`。
- 修复加载进度文案与实际操作不一致：并行块移除初始 "正在加载仓库、分支和提交..." 文案（让 `refreshSelectors` 自行投递 "加载仓库..." / "加载分支..."），移除 `getGitCommits` 的 `onProgress` 回调避免文案交错；`beginCommitReload` 统一用 "正在加载..." 通用文案，由后续操作投递具体进度。
- 修复切换仓库/分支时提交个数和页脚残留旧文案：`showLoadingProgress` 新增隐藏 `commitFooter`、断开 `commitLoadObserver`、清空 `countLabel` 和 `commits` 数组，确保切换时不会残留 "已加载全部 N 条提交" / "继续滚动以加载更多提交" 等过期文案。
