- Git 高频变卡根因排查：`UncommittedFilesWatcher` 为每个仓库监听 `**/*`，每次文件事件立即刷新；刷新中再来事件会 abort 当前任务并重跑。每轮路径刷新并发启动 `git status`、cached diff、unstaged diff 三个进程，多仓库/父子仓库监听范围重叠及 OneDrive 高频事件会放大为进程启动/取消抖动。另有 index 每次变化触发 `RepoSubmoduleWatcher.rescanRepository()` 的过宽重扫。普通文件编辑并不会直接触发 `git log`。
- 拟定根因修复方案：把工作区状态刷新改成单仓库 single-flight 状态机，在途批次不因普通新事件 abort，只累积下一批路径并在结束后紧接执行；仅 HEAD/分支代际切换允许取消。删除 index→子模块重扫的错误耦合，子模块拓扑继续由既有 `.gitmodules` 专用 watcher 和明确 Git 同步结果驱动；父仓库 watcher 收到子模块内部路径时将事件归属到最深仓库，避免父子重复刷新。保持现有三命令并行和路径增量语义，不采用定时器/debounce。
