- Commit editor 与 Repo 弹窗列表不同步（2026-08-27，已修复）：根因是 Repo 弹窗直接消费 `GitRepoController.totalRepoList`，但 Commit editor 的 `commitRepositories` 仅从 `UncommittedFilesWatcher.listCurrentHeadBranches()` 构建；新仓库需异步完成 git-dir、HEAD、分支及未提交 watcher 链路后才出现。现 `GitkViewProvider.syncCommitRepositories()` 直接遍历 `repoController.totalRepoList` 建卡，HEAD/未提交数据仅作为卡片内容补充；仓库拓扑发布时若 Commit editor 已打开，立即同步并更新卡片。同步函数去掉伪 async，所有打开/刷新调用同步执行。`npm run compile` 和 diagnostics 通过。
