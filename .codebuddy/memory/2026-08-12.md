- 排查 Changed Files 点击不跳转：排除“首次 Webview 消息丢失/延时”假设。更符合稳定循环的是 `CustomDiffPanel` 被 `createWebviewPanel(..., ViewColumn.Beside, ...)` 创建/激活到侧边编辑器列，而 `canShowMultiDiff()` 仅在当前活跃编辑器 URI scheme 为 `multi-diff-editor` 时为真；焦点落在主 Webview 或普通编辑器时，`onDidChangeActiveTextEditor` 会将 `multiDiffVisible=false`，主 Webview 消息处理随即跳过 `selectChangedFile`，故首次仅本地高亮。下一次点击时 Diff 已成为活跃编辑器，分支才执行。应以 `CustomDiffPanel.panel?.visible` 或面板内部可用性为准，不应通过 activeTextEditor 误判独立 Custom Diff 面板可见性。
- 排查搜索清空触发的仓库/分支重载：`gitkViewProvider.ts` 的 `runEffect('search')` 在关键词为空时调用 `refreshSearchCleared()`，后者调用默认 `reloadSelectors=true` 的 `refresh()`，进而执行仓库发现与分支加载。非空关键词但搜索结果为零仅覆盖 commits，不会刷新 selector。若需修复，应优先由 `rawCommits` 恢复搜索前图数据；`refresh(false)` 只能避免仓库扫描，仍会加载分支。
- 修复 `CustomDiffPanel` 新增空文件的重复行显示：`splitLines()` 对空字符串返回空数组而非单个空行，避免 Myers 差异把不存在的旧侧行与新增首行配对。`npm run compile` 通过。- 调整 `src/webview/gitkViewProvider.ts` 的仓库/分支选择与搜索交互：仓库刷新同步置 `reposLoading` 与 `branchesLoading`，失败或取消会共同复位；分支勾选不再触发分支下拉加载/关闭，并用待同步的本地选择保护连续多选、全选和清空不被旧状态快照覆盖；虚拟提交固定按 `Changes`、`Staged Changes` 排序；分支选择变化时若已有关键词则重新执行 `searchCommits(rootUri, keywords, selectedBranches)`。`npm run compile` 和该文件诊断均通过。
- 静态排查 Changed Files 偶发需二击：主列表点击与 `CustomDiffPanel` 视口滚动会异步双向写入 `selectedPath`。后者只校验同一批 `diffGeneration`，不能排除同一提交内旧文件的晚到事件，可能将刚选的新文件覆盖回旧文件；随后完整 `stateUpdate` 重绘列表，造成第一次点击被撤销。建议为单次文件选择增加序列号/版本，或在短暂用户点击抑制期间忽略 Diff 面板的视口回写。
- 恢复 `DiffReader.readWorkingTreeFile` 的结构化 `{ content, error? }` 返回；读取失败时由 `CustomDiffPanel` 将单文件具体错误写入 `DiffPayload.error` 并在 Multi-Diff 中展示。`npm run compile` 通过。
- 更正 Changed Files 点击问题判断：排除延时/首次创建假设。需重点验证 `canShowMultiDiff()` 以 `activeTextEditor` 的 `multi-diff-editor` scheme 判定可见性，是否在焦点切回主 Webview 时错误置 `multiDiffVisible=false`，使消息处理跳过 `selectChangedFile`；该视图生命周期条件更符合“每轮首击仅亮、下一击跳转”的循环。
- 确认二进制可比对性来自 `--numstat`，不影响 `--raw` 独立提供的 `oldObjectId` / `newObjectId`；二进制文件仍可显示 Git diff 的 index/blob SHA。
- 实现二进制差异展示：`CommitFile.isBinary` 保留 `--numstat` 的 `- -` 信号；commit、staged、changes 均采集 raw/numstat 元数据，工作区变更按各自 diff 基准合并对象 ID；`DiffReader` 跳过二进制 UTF-8 内容读取，`CustomDiffPanel` 显示“二进制文件不同”及现有 `index <old>..<new>`。`npm run compile` 通过。
