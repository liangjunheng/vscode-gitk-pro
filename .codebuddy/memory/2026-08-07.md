# 工作记录

- 提交图数据源改为单次 `git log --topo-order`（完整 hash、完整父列表、所选 refs 可达提交并集），不再使用第一父链或多个 `repo.log()` 的非全局拓扑顺序。`buildGraph()` 改为逐行完整车道转换：过滤不可见父节点、共同父去重、为所有存活车道生成位置迁移边，解决 merge、分叉和截断造成的重复/悬空/错连。SVG 曲线统一按行顶部到下一行底部绘制；引用标签路径增加背景色横向避让通道，垂直线不会与标签重叠。图宽按车道与标签需求计算。`npm run compile` 通过，相关文件无诊断。
- Branchs 首次加载默认选中 `getCurrentGitBranch()` 返回的本地当前分支。引用标签统一定位在最右侧车道之后，提交节点通过横线连接到该标签列，不再覆盖任意车道。`buildGraph()` 对八爪合并仅保留前两个可见父提交，以二叉连接表达单行分叉。`npm run compile` 通过，相关文件无诊断。

- Multi-Diff 文件名栏原有 Unicode `⌄` 已替换为内嵌 SVG chevron，并升级 `.chevron` 为 18px 圆角图标容器，包含主题自适应描边和文件标题悬停态。正常 Diff 和读取失败分支同步更新；`npm run compile` 与 `git diff --check -- src/customDiffPanel.ts` 通过，`customDiffPanel.ts` 仅保留既有未使用 `context` 提示。
- 用户要求还原工具栏修改点导航的原始文字箭头，已将 SVG 图标和 `.change-navigation` 容器恢复为独立的 `↑` / `↓` 按钮及原 `.toolbar-button` 样式；文件名栏 SVG 下箭头保持不变。`npm run compile` 和 `git diff --check -- src/customDiffPanel.ts` 通过。
- 提交图 SVG 改为：延续车道先从行顶连到提交节点，当前提交的父边从节点中心继续至行底；跨车道曲线以节点为起点，节点最后绘制覆盖接合点，解决弧线脱离节点与车道断续。新起车道不绘制节点顶部入线，避免最新提交出现额外上行支路；引用标签仍始终经横线连接到节点，避免标签悬空。`npm run compile` 通过，`gitLogProvider.ts`、`gitkViewProvider.ts` 无诊断。
- 分支图列宽按所有车道的总宽度 `naturalGraphW` 自适应，且通过 `max(30ch, naturalGraphW)` 保证最少显示 30 个字符宽；引用标签宽度不参与列宽计算。`npm run compile` 通过，`gitkViewProvider.ts` 无诊断。
- 提交列表每一行的分支图容器在该提交存在引用时新增原生悬停提示，使用 `c.refs` 的全部分支/引用名称按逗号分隔显示。`npm run compile` 通过，`gitkViewProvider.ts` 无诊断。
- 已完成提交加载性能只读评估：优先减少 Webview 500 行提交图的重复整表/SVG 重绘，其次延后首次 `selectCommit()` 引发的 `diff-tree` 和全量 Diff 打开；Git 读取路径当前是 `git log --topo-order --max-count=500` 并行 `for-each-ref`，完整刷新还并行读取工作区状态。可选优化包括：虚拟列表、选中状态局部更新、批量绘图、事件委托、按需加载 Diff、分页/较低初始提交数、缓存 refs/选择器、工作区状态异步化、取消过期请求、增量刷新、减少 Git log 字段与 refs 范围、仓库并发限流及性能埋点。
- 描述列展开模板已改为 `Commit`、`Parents`、`Author`、`Committer`、`Date`、空行、提交主题、完整提交正文的固定顺序。`getGitCommits()` 的单次 `git log` 格式加入 `%cn` / `%ce`，并为 `GitCommit` 提供提交者名和邮箱；缺失时回退作者信息，未增加额外 Git 请求。`npm run compile` 通过，相关文件无诊断。
